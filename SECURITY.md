# Security Policy

## Reporting a vulnerability

Please report security issues privately via [GitHub Security Advisories](https://github.com/pvlltvk/proxeus/security/advisories/new) rather than a public issue.

If that isn't accessible to you, email pvlltvk@gmail.com.

Please include:
- The affected version/commit.
- Steps to reproduce or a proof of concept.
- The impact you'd expect (e.g. data exposure across backends, DoS, auth bypass).

## Supported versions

proxeus doesn't yet have a formal support/backport policy — fixes land on `main` and the latest release. If that changes, this section will be updated.
